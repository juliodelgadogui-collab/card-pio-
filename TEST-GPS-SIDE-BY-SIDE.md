# EventMenu GO GPS Premium - build de teste lado a lado

Este branch altera somente o build debug para usar o applicationId `br.com.eventmenu.go.gpspremium` e o rótulo `EventMenu GO GPS`, permitindo instalar o APK ao lado de uma instalação existente do EventMenu GO sem conflito de assinatura.

O build release mantém o applicationId oficial `br.com.eventmenu.go`.
